# DIG — Phase 0 Prototype

「持っている一枚から、次に掘る一枚へ。」レコード収集アプリ DIG の Phase 0 プロトタイプです。

Phase 0 は店舗連携・他ユーザーのデータに依存せず、**ユーザー単独で価値が完結する**ことを前提に、以下の機能を実装しています。

| # | 機能 | 実装内容 |
|---|---|---|
| 01 | コレクション管理 | レコードの登録・検索・ALL/LP/12"/7" フィルター |
| 02 | 写真でレコード登録 | ジャケット撮影 → AI認識（モック）→ 編集して確定 |
| 03 | DIG DNA分析 | ジャンル・年代・アーティスト・レーベル傾向のレーダーチャート／ドーナツチャート |
| 04 | Spotify連携 | 連携トグル（モック）、DNAモード切り替え（コレクションのみ／Spotifyのみ／統合） |
| 05 | Spotify統合レコメンド | 一致度スコア付きおすすめ、一致ポイントの明示 |
| 06 | Wantlist | 欲しい盤の登録・自分だけの目撃情報記録、フィルター |
| 07 | My DIG Log | 自分の発見をいつ・どこで・何を、の個人記録として蓄積 |
| 08 | ゲーミフィケーション | XP・レベル・バッジ・ウィークリーチャレンジ（すべてユーザー自身の行動から算出） |
| 09 | プロフィール | レベル・XP・コレクション数・バッジ・Weekly Digsなどの実績サマリー |

店舗ページや共有DIG MAPなど、他ユーザー・店舗データに依存するPhase 1以降の機能は未実装です。

## スタック

- React + TypeScript + Vite
- Tailwind CSS v4
- react-router-dom（`HashRouter`）
- recharts（DIG DNAのレーダー／ドーナツチャート）
- lucide-react（アイコン）
- 状態管理は React Context + `localStorage` 永続化（バックエンドなしのフロントエンド完結プロトタイプ）

## セットアップ

```bash
npm install
npm run dev
```

`npm run build` で本番ビルド、`npm run lint` で Oxlint によるチェックができます。

## 注意事項（プロトタイプの制約）

- 写真AI認識・Spotify連携は実際の外部APIには接続していないモック実装です。
- レコードジャケット画像は用意していないため、ジャンルカラーのグラデーションでカバーアートを表現しています。
- データはすべて `localStorage` に保存され、ブラウザ・端末をまたいだ同期はありません。
